# Brand Color System

This document defines the official color palette for the application and explains the purpose, usage, and best practices for each color.  
The goal is to ensure **visual consistency**, **accessibility**, and **clear hierarchy** across our product.

---

## 🎨 Color Palette Overview

| Role | Name | Hex |
|----|----|----|
| Dominant | Yellow | `#fed531` |
| Support | Charcoal | `#3a3a3a` |
| Neutral | Soft White | `#fafaf9` |
| Staging | Olive-oil green | `#2e3a2f` |

---

## 1. Dominant Color — Yellow

**Hex:** `#fed531`

### Purpose
The dominant color represents the **core identity of our brand**.  
It is the most recognizable and emotionally expressive color in the system.

This yellow, along with the support and neutral colors, conveys:
- Simplicity
- Transparency
- Safety
- Confidency
- Authority
- Intelligence


### Usage Guidelines
Use sparingly but intentionally:
- Primary call-to-action buttons
- Key highlights
- Brand marks and accents
- Interactive emphasis (active states, focus rings)

### Do
- Use for **high-importance UI elements**
- Pair with charcoal text for strong contrast

### Don’t
- Use as a background for long text blocks
- Overuse across large surfaces (causes visual fatigue)

---

## 2. Support Color — Charcoal

**Hex:** `#3a3a3a`

### Purpose
Charcoal is the **structural backbone** of the UI.  
It provides contrast, stability, and readability while allowing the dominant color to stand out.

### Usage Guidelines
- Primary text color
- Icons and UI controls
- Headers and navigation
- Borders and dividers

### Accessibility
- Excellent contrast on soft white and yellow
- Safe for long-form reading

---

## 3. Neutral Color — Soft White

**Hex:** `#fafaf9`

### Purpose
The neutral color defines the **canvas** of the application.  
It reduces visual noise and improves content legibility.

### Usage Guidelines
- Main backgrounds
- Content surfaces
- Cards and containers
- Page layouts

### Why not pure white?
Soft white reduces eye strain and feels more organic, especially when paired with warm tones like yellow.

---

## 4. Staging Color — Deep Green

**Hex:** `#2e3a2f`

### Purpose
The staging color is **not part of the primary brand expression**.  
It exists to create **contrast zones**, **depth**, and **separation** when needed.

Think of it as a *stage* where the brand can sit on top and where *queja-cierta* is the main actor, and will shine on this stage.

### Usage Guidelines
- Backgrounds behind the full logo (especially light or monochrome versions)
- Hero sections
- Highlight panels
- Thematic sections that need emotional grounding

### Key Rule
> The staging color should **never compete** with the dominant yellow — it exists to support it.

---

## 🎭 Color Hierarchy

1. **Soft White** — base canvas
2. **Charcoal** — structure & readability
3. **Yellow** — attention & brand identity
4. **Deep Green** — contrast & staging

This hierarchy ensures visual clarity and prevents color overload.

---

## 🧠 Accessibility Considerations

- Always maintain WCAG contrast ratios for text
> WCAG stands for Web Content Accessibility Guidelines
- Preferred text pairings:
  - Charcoal on Soft White ✅
  - Charcoal on Yellow ✅
  - Soft White on Deep Green ✅
- Avoid:
  - Yellow text on Soft White ❌
  - Yellow text on Green ❌
